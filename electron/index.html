먼저 설치 여부를 확인한 뒤, 필요한 항목의 설치 버튼을 누르세요. 최초 설치에는 인터넷 연결이 필요합니다.

    GPU SR: 아직 확인하지 않았습니다.

    PyTorch 자동 설치는 CPU용입니다. GPU SR에는 지원 NVIDIA GPU·드라이버와 CUDA용 PyTorch가 필요합니다.

    설치 여부 확인을 눌러 시작하세요.
